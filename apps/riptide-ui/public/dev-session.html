Seed session

Fork-only tool. It stores a real sign-in credential for your own account in this browser so this fork can reach your HumanLayer backend. Only use it on a device you trust, over HTTPS. Do not ship this page in the real product.

How to get the token

Only the refresh token is needed — the app exchanges it for a fresh access token on load.

  1. Sign in to the real HumanLayer web app on a computer.
  2. Open the browser console (F12 → Console) and run: 
    (() => {
  const k = Object.keys(localStorage).find(k => k.startsWith('workos:refresh-token:'));
  return k ? { clientId: k.split(':').pop(), refreshToken: localStorage.getItem(k) } : 'not found';
})()
  3. Copy the clientId and refreshToken it prints, get them to this device (e.g. message them to yourself), and paste them above.
  4. Build this fork with the same VITE_PUBLIC_WORKOS_CLIENT_ID, API origin and sync origin as production (see FORK_MOBILE.md).

If the app still shows you signed out after seeding, the sign-in service likely rejected the refresh from this origin — see FORK_MOBILE.md for what that means.
